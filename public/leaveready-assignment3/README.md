# LeaveReady — Assignment 3 · Part 2

Interactive behaviour prototype based on Assignment 2. Open `index.html` for the self-contained demo.

- Normal commute flow: Today → Preferences → Choose a route → Journey preview (6 steps) → Finish.
- Critical states: Cannot, Unsure, Corrected, Says no.
- Click **Participant mode** for a two-minute silent usability test.
- All route, ETA, fare, and feed data is scripted fictional prototype data.
- No live AI, payment, booking, location tracking, notification or calendar connection.
- Only the main sample route has complete stop-level data. Incomplete route data is not invented.
