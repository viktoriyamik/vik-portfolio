# LeaveReady — Interactive Behaviour Prototype

A scenario-based, fixed-response prototype of an AI-assisted commuting experience.

- **Portfolio case:** https://vik.ooo/case-studies/leaveready/
- **Internal prototype:** https://vik.ooo/leaveready-prototype/
- **Source today:** https://github.com/viktoriyamik/vik-portfolio/tree/main/public/leaveready-prototype

## Run locally

Open `index.html` in a modern browser. It is self-contained and does not require an application server or API keys.

## Behaviour and evidence boundaries

The prototype shows journey planning, route comparison, preview steps and taxi-related critical states: Cannot, Unsure, Corrected and Says No. Its routes, fares, update timestamps and AI responses are predefined examples; they are not fetched from live transport providers. No GPS tracking, booking, payment, notifications or persistent memory modifications occur.
